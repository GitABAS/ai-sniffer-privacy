# 爱嗅探隐私政策 / Ai Sniffer Privacy Policy

这是爱嗅探（`com.weep.mobile`）的 GitHub Pages 隐私政策页面。

## 发布方式

1. 在 GitHub 新建一个公开仓库，例如 `ai-sniffer-privacy`。
2. 将本目录的 `index.html` 上传到仓库根目录。
3. 在仓库 **Settings → Pages** 中选择 **Deploy from a branch**。
4. Branch 选择 `main`，目录选择 `/(root)`，点击 **Save**。
5. 页面通常会发布到：`https://你的用户名.github.io/ai-sniffer-privacy/`。
6. 将 `index.html` 中两处联系说明替换为真实地址：`https://github.com/你的用户名/ai-sniffer-privacy/issues`。
7. 将最终 GitHub Pages HTTPS 地址填写到 Google Play Console 的“隐私政策”字段。

请保持仓库公开，确保用户无需登录即可访问隐私政策。
